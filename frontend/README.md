# JurisFind — frontend

Aplicação Angular 21 (componentes standalone, SCSS, Router, HttpClient, Reactive Forms).

```bash
npm install
npm start        # http://localhost:4300, com /api encaminhado para http://127.0.0.1:8010
npm run build    # gera dist/frontend
```

O endereço da API usado em desenvolvimento fica em `proxy.conf.json`. Instruções completas no
[README da raiz](../README.md).
